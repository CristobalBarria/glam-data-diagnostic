# Formulaire de diagnostic des pratiques de gestion et de curation des données patrimoniales

Master Thesis in Museology\
University of Neuchatel\
Academic Year 2026

------------------------------------------------------------------------

## Project Overview

This repository contains the research and development work for a
Master's thesis focused on designing a sondage to assess
the state of museum datasets prior to their integration into a federated
Linked Open Data platform.

The project proposes a structured questionnaire, formalized in JSON and
executable via a web interface, to systematically collect information
about:

-   data structure
-   metadata governance
-   normalization practices
-   uncertainty management
-   duplication levels
-   lifecycle management
-   rights and restrictions
-   publication readiness
